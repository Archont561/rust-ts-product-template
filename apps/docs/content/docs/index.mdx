Welcome to the product documentation powered by **Fumadocs**.

- **Web (`apps/web`):** Pure-Rust typed Axum OpenAPI server (`/api/hello`) compiled into a static Alpine Linux binary (`Dockerfile`).
- **Desktop (`apps/desktop`):** Tauri v2 native shell for Linux, macOS, and Windows.
- **Mobile (`apps/mobile`):** Tauri v2 Mobile shell with native plugins (haptics, biometrics, barcode scanner, SQLite, notifications, deep links).
- **Browser Extension (`apps/extension`):** WXT Manifest V3 extension for Chrome, Firefox, and Safari.
